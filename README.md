# Revisão de Base Java – Programação Orientada a Objetos (POO)

Repositório criado para a atividade de revisão de conceitos fundamentais de Programação Orientada a Objetos em Java, contendo 10 exercícios práticos implementados em classes separadas.

## 👥 Autoria e Divisão das Tarefas

* **Brenno Giovanni:** Questões de 01 a 05 (`Pessoa`, `Carro`, `Calculadora`, `Aluno`, `Produto`).
* **Você (Você):** Questões de 06 a 10 (`ContaBancaria`, `Retangulo`, `Funcionario`, `ConversorTemperatura`, `Livro`).

---

## 📂 Estrutura de Classes (`/src`)

### Desenvolvidas por Brenno Giovanni (Questões 1–5):
1. **`Pessoa.java`** - Atributos (`nome`, `idade`, `altura`) e instanciação de objetos no método `main`.
2. **`Carro.java`** - Atributos (`modelo`, `marca`, `ano`) e método `exibirInformacoes()`.
3. **`Calculadora.java`** - Métodos de operações matemáticas básicas (`somar`, `subtrair`, `multiplicar`, `dividir`) com parâmetros e retorno.
4. **`Aluno.java`** - Atributos (`nome`, `nota1`, `nota2`), cálculo de média e verificação de situação (`Aprovado`, `Recuperação`, `Reprovado`).
5. **`Produto.java`** - Atributos (`nome`, `preco`, `estoque`) com métodos para gerenciar estoque (`adicionar`, `remover`) e calcular o valor total.

### Desenvolvidas por Você (Questões 6–10):
6. **`ContaBancaria.java`** - Atributos (`titular`, `saldo`) com métodos para `depositar`, `sacar` e `consultarSaldo()`.
7. **`Retangulo.java`** - Atributos (`base`, `altura`) com métodos de retorno para cálculo de área e perímetro.
8. **`Funcionario.java`** - Atributos (`nome`, `cargo`, `salario`) com método para aplicar aumento percentual (`aumentarSalario`) e exibir dados atualizados.
9. **`ConversorTemperatura.java`** - Métodos com parâmetros e retorno para conversão entre Celsius e Fahrenheit.
10. **`Livro.java`** - Sistema de cadastro com atributos (`titulo`, `autor`, `isbn`, `disponivel`) e métodos para `emprestar`, `devolver` e `exibir` o estado.
